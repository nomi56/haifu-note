# 🀄 麻雀牌譜記録 (haifu-note)

自分の打ち筋（摸打＝ツモ・打牌・チー/ポン/カン・リーチ）を記録するための個人用Webアプリ。対局結果や点数ではなく、実際にどう打ったかを局ごとに残して後から見返すことを目的としています。

- 記録単位: 自分の席のみ
- 牌の表記: MPSZ表記（例: `5m`, `0m`=赤5, `1z`=東）＋ Unicodeの麻雀牌絵文字
- 打った牌がツモ牌と同じなら「ツモ切り」、違えば「手出し」を自動判定
- リーチを宣言した打牌は横向き表示
- 局を確定すると履歴に追加され、折りたたみで一覧できる
- ブラウザのlocalStorageに常時自動保存（安全網）
- Google Driveへの保存/読み込みに対応（`drive.file`スコープ、アプリ専用フォルダ「麻雀牌譜記録」に1セッション=1ファイルで保存）

## ローカル開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

`vite.config.ts`の`base`は`/haifu-note/`に設定済み（GitHub Pagesのプロジェクトサイト用）。

## GitHub Pagesへの公開（初回のみ・手動作業）

1. GitHubリポジトリの **Settings → Pages → Build and deployment → Source** を「**GitHub Actions**」に変更する。
2. `main`ブランチにpushすると`.github/workflows/deploy.yml`が自動でビルド・デプロイする（`workflow_dispatch`での手動実行も可）。
3. 公開後のURLは `https://<GitHubユーザー名>.github.io/haifu-note/` になる。

## Google Drive連携のセットアップ（初回のみ・ユーザー自身の作業）

このアプリはGitHub Pages上の静的サイトのため、サーバー側でOAuthの秘密情報を保持できません。そのため **OAuth Client IDはアプリ内の「Drive設定」画面から入力し、ブラウザのlocalStorageに保存**する方式にしています（ビルド時の埋め込みは行いません）。

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成（または既存のものを使用）。
2. **APIとサービス → ライブラリ** で「Google Drive API」を有効化する。
3. **APIとサービス → OAuth同意画面** を設定する:
   - User Type: 「External」
   - スコープに `https://www.googleapis.com/auth/drive.file` を追加
   - 「公開ステータス」は **Testing のままでOK**（個人利用なのでGoogleの審査は不要）。ただし**テストユーザーに自分のGoogleアカウントを追加**すること。
4. **認証情報 → 認証情報を作成 → OAuthクライアントID** を作成する:
   - アプリケーションの種類: 「ウェブ アプリケーション」
   - 承認済みのJavaScript生成元に以下を追加:
     - `https://<GitHubユーザー名>.github.io`（本番用。パス部分`/haifu-note/`は不要、オリジンのみでよい）
     - `http://localhost:5173`（`npm run dev`でのローカル動作確認をしたい場合）
   - リダイレクトURIの設定は不要（トークンフローを使用しているため）
5. 発行された **クライアントID** をコピーし、デプロイ後のアプリを開いて「**Drive設定**」タブに貼り付け → 「Googleに接続」→ 同意画面で許可する。

### 注意点

- 発行したトークンは短命（約1時間）で、リフレッシュトークンを保持しないフローのため、時間が経つと再接続が必要になる。
- OAuth同意画面が「Testing」状態のままだと、Googleの設定によりテストユーザーのトークンが7日で失効することがある。個人利用なら都度「Googleに接続」を押し直せば問題ない。
- 保存先は各ユーザーのDrive内に自動作成される「麻雀牌譜記録」フォルダ。`drive.file`スコープのため、このアプリが作成したファイルにのみアクセスできる。

## データの保存単位

1つの「牌譜帳（セッション）」に複数の局をまとめて記録し、Drive上には1セッション=1つのJSONファイルとして保存する。局を確定するたびにセッション内の履歴に追加され、そのままDriveへ保存（上書き）できる。

## 既知の制限

- 環境やフォントによっては、Unicodeの麻雀牌絵文字（🀀-🀛など）の一部が正しく表示されないことがある（フォント側のカバレッジ次第）。主要デスクトップ/モバイルブラウザでは概ね問題ない。
- 他家の手牌・河、点数計算・スコア管理は対象外（自分の打ち筋の記録に特化）。
