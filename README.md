# 🀄 麻雀牌譜記録 (haifu-note)

自分の打ち筋（摸打＝ツモ・打牌・チー/ポン/カン・リーチ）を記録するための個人用Webアプリ。対局結果や点数ではなく、実際にどう打ったかを局ごとに残して後から見返すことを目的としています。

- 記録単位: 自分の席のみ
- 牌の表記: MPSZ表記（例: `5m`, `0m`=赤5, `1z`=東）＋ Unicodeの麻雀牌絵文字
- 打った牌がツモ牌と同じなら「ツモ切り」、違えば「手出し」を自動判定
- リーチを宣言した打牌は横向き表示
- 局を確定すると履歴に追加され、折りたたみで一覧できる
- ブラウザのlocalStorageに常時自動保存（安全網）
- 牌譜帳（セッション）をJSONファイルとしてダウンロード／ファイルからの読み込みに対応（特別な設定不要。保存先はブラウザのダウンロード機能に任せるため、Google DriveのデスクトップアプリやiCloud Drive等で同期されたフォルダに保存すれば、そのままWebストレージ上にも残せる）

## ローカル開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

`vite.config.ts`の`base`は`/haifu-note/`に設定済み（GitHub Pagesのプロジェクトサイト用）。

## GitHub Pagesへの公開（初回のみ・手動作業）

1. GitHubリポジトリの **Settings → Pages → Build and deployment → Source** を「**GitHub Actions**」に変更する。
2. `main`ブランチにpushすると`.github/workflows/deploy.yml`が自動でビルド・デプロイする（`workflow_dispatch`での手動実行も可）。
3. 公開後のURLは `https://<GitHubユーザー名>.github.io/haifu-note/` になる。

## 牌譜の保存・読込

「保存・読込」タブから:

- **現在のセッションをダウンロード**: 牌譜帳をJSONファイルとしてダウンロードする（ファイル名は「セッション名.json」、未入力なら「kifu-作成日.json」）
- **ファイルから読み込む**: 以前ダウンロードしたJSONファイルを選択して読み込む（現在編集中の内容は破棄されるため確認ダイアログが出る）

OAuth設定やクラウドAPIの発行は不要。保存先を自分でGoogle Drive等の同期フォルダに指定すれば、結果的にWebストレージにも保存される。

## データの保存単位

1つの「牌譜帳（セッション）」に複数の局をまとめて記録し、ダウンロード時は1セッション=1つのJSONファイルになる。局を確定するたびにセッション内の履歴に追加され、都度ダウンロードし直せば最新の状態を書き出せる。

## 既知の制限

- 環境やフォントによっては、Unicodeの麻雀牌絵文字（🀀-🀛など）の一部が正しく表示されないことがある（フォント側のカバレッジ次第）。主要デスクトップ/モバイルブラウザでは概ね問題ない。
- 他家の手牌・河、点数計算・スコア管理は対象外（自分の打ち筋の記録に特化）。
- ファイル保存はブラウザのダウンロード機能を使うため、同じファイルへの自動上書きはできない（都度ダウンロードし直す運用になる）。
